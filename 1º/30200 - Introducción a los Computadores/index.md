# Introducción a los Computadores: Lógica, Circuitos y Arquitectura

Bienvenido al manual completo de **Introducción a los Computadores** para el Grado en Ingeniería Informática. Esta asignatura une el álgebra de Boole y la lógica de circuitos con el hardware de computadores y la arquitectura del procesador. Es la asignatura donde se revela cómo impulsos eléctricos en transistores se organizan para codificar datos y ejecutar instrucciones de software de bajo nivel.

## Orientación Práctica y Laboratorio

Para dominar los laboratorios y teoría de esta materia:
1.  **Simulación de Circuitos (Logisim / Multisim)**: Las lecciones se conectan directamente con simuladores gráficos de compuertas TTL.
2.  **Conversión Numérica Automatizada (Python)**: Proporciona scripts de conversión rápida útiles para autoevaluación.
3.  **Lenguaje Ensamblador**: Se utiliza un conjunto simplificado de instrucciones estilo MIPS para modelar la transferencia entre registros de la CPU de forma comprensible.
