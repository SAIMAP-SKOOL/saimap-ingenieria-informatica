## Estructura del Manual

El manual se divide en cuatro bloques temáticos que cubren desde los fundamentos algebraicos hasta el cálculo numérico y la computación científica:

### Bloque 1: Herramientas Básicas y Análisis de Sucesiones
*   [Tema 1: Números Complejos](file:///d:/Usuario/SAIMAP/SAIMAP%20-%20UNIVERSIDAD/Grado%20en%20Ingenier%C3%ADa%20Inform%C3%A1tica/1%C2%BA/30202%20-%20Matem%C3%A1ticas%20I/tema_01_numeros_complejos.md)
    *   Definición y representación geométrica en $\mathbb{C}$.
    *   Operaciones aritméticas y formas de representación (binómica, polar, exponencial).
    *   Radicación de números complejos.
    *   *Toque informático*: Fractales, rotaciones en gráficos 2D y señales digitales.
*   [Tema 2: Sucesiones Numéricas](file:///d:/Usuario/SAIMAP/SAIMAP%20-%20UNIVERSIDAD/Grado%20en%20Ingenier%C3%ADa%20Inform%C3%A1tica/1%C2%BA/30202%20-%20Matem%C3%A1ticas%20I/tema_02_sucesiones_numericas.md)
    *   Concepto de límite e indeterminaciones.
    *   Criterios de convergencia y cálculo analítico de límites.
    *   *Toque informático*: Relación con la complejidad asintótica y bucles recursivos.
*   [Tema 3: Series Matemáticas](file:///d:/Usuario/SAIMAP/SAIMAP%20-%20UNIVERSIDAD/Grado%20en%20Ingenier%C3%ADa%20Inform%C3%A1tica/1%C2%BA/30202%20-%20Matem%C3%A1ticas%20I/tema_03_series_matematicas.md)
    *   Suma de series, series geométricas y armónicas.
    *   Criterios para series de términos positivos y series alternadas (Leibniz).

### Bloque 2: Cálculo Diferencial en una Variable
*   [Tema 4: Cálculo de Límites y Continuidad](file:///d:/Usuario/SAIMAP/SAIMAP%20-%20UNIVERSIDAD/Grado%20en%20Ingenier%C3%ADa%20Inform%C3%A1tica/1%C2%BA/30202%20-%20Matem%C3%A1ticas%20I/tema_04_limites_y_continuidad.md)

## Requisitos de Software y Configuración

Para ejecutar los ejemplos de código en Python distribuidos por el manual, se recomienda contar con un entorno de desarrollo de Python (versión 3.8 o superior) e instalar las siguientes librerías científicas:

```bash
pip install numpy scipy matplotlib sympy
```

*   **SymPy**: Se utiliza para el cálculo simbólico (derivadas analíticas, límites, polinomios de Taylor exactos y resolución algebraica).
*   **NumPy**: Se utiliza para el cálculo numérico optimizado y almacenamiento vectorial eficiente.
*   **Matplotlib**: Se utiliza para generar gráficos bidimensionales que ilustran la convergencia de sucesiones, la aproximación de Taylor y las funciones estudiadas.
